# 🎬 IMDb Movie Data Analysis

This project explores **IMDb movie data** using Python to uncover patterns in movie genres, durations, and ratings. Through various filtering and analytical techniques, the study provides insights into how content rating, genre, and actor presence impact movie characteristics.

---

## 📁 Project Structure

- `imdb_movie_analysis.ipynb` – Jupyter Notebook with the full analysis and visualizations  
- `README.md` – Documentation of the project

---

## 🧰 Tools & Libraries Used

- Python 3
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib / Seaborn (if used for visuals)

---

## 🔍 Key Analyses Performed

1. **🎭 Genre Analysis**
   - Examined the distribution of movies by genre
   - Calculated average duration for each genre

2. **🔞 Content Rating Insights**
   - Analyzed average movie durations based on content rating (e.g., PG, R)

3. **🧹 Handling Missing Data**
   - Replaced NaN values with 'Unknown' to improve data quality and consistency

4. **📊 Movies per Genre & Rating**
   - Counted number of movies per genre grouped by content rating
   - Calculated max, min, and mean star ratings for better comparison

5. **🎯 Specific Genre Filtering**
   - Focused analysis on **'Crime'**, **'Action'**, and **'Comedy'** genres
   - Applied filters based on rating and duration to find top entries

6. **👤 Actor-Based Filtering**
   - Extracted and listed all movies featuring **Tim Robbins**

---

## 📈 Summary of Insights

- Some genres (e.g., Action, Comedy) have significantly different average durations.
- Content rating has a notable effect on movie duration—R-rated movies tend to be longer.
- Filtering by genre and rating helps identify top-performing content.
- Tim Robbins appeared in several well-rated and lengthy films.
